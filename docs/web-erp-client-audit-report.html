1. Scope

This report covers the web ERP application only (the system backed by its REST API), independent of the separately-delivered Owner Android App audit. It verifies core business workflows, data integrity, role-based access control, and multi-tenant isolation using real dummy data created through the live API — not fabricated numbers — against a local development database, never the production database.

2. Method

  • All records below were created by calling the real backend API as a logged-in TENANT_ADMIN user, exercising actual validation, business logic, and database writes exactly as the web app itself would.
  • A dedicated CASHIER role account was created to independently verify permission boundaries.
  • The full automated backend test suite was run fresh in this session, not recalled from a prior run.
Disclosure: Verification here is at the API/data level, which is where the actual business logic and security enforcement live. Actual browser rendering/visual layout was not independently inspected as part of this report — the client should continue to visually confirm the UI as they use it.
